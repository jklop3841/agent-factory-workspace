# Prior-Art Boundary for Organization Before Consciousness

This file exists to prevent accidental overclaiming.

## Established or pre-existing components

### 1. Holons / Holarchy / Janus Effect

Holonic multi-agent systems have long modeled entities that are simultaneously autonomous wholes and parts of larger wholes. A holon can be viewed at one level as an atomic agent and at another level as an organization of sub-holons. This directly precedes the intuition that an agent may be both subordinate and supervisory depending on the level of observation.

### 2. Organizational and dynamic roles

Multi-agent organizational theory already treats roles as context- and organization-dependent rather than purely intrinsic agent identities. Agents can hold multiple roles and role membership can change.

### 3. Recursive Agent Harnesses

Recent LLM-agent work formalizes recursive harness structures in which a parent agent can generate and run sub-agent harnesses.

Seed:
- Lumer et al. (2026), "Recursive Agent Harnesses", arXiv:2606.13643.

### 4. Self-organizing roles in LLM multi-agent systems

Recent experiments show that LLM agents can invent specialized roles and shallow hierarchies without preassigned role labels under some coordination protocols.

Seed:
- Dochkina (2026), "Drop the Hierarchy and Roles: How Self-Organizing LLM Agents Outperform Designed Structures", arXiv:2603.28990.

### 5. Objective drift in long-horizon agents

Long-horizon agent research already identifies objective drift as a failure mode.

Seed:
- Park & Kwon (2026), "Multi²: Hierarchical Multi-Agent Decision-Making with LLM-Based Agents in Interactive Environments", arXiv:2606.03698.

## Candidate contribution of OBC

OBC does NOT claim novelty on the components above.

The candidate contribution is this integrated causal hypothesis:

```text
recursive delegation
  -> relational role relativity
  -> topology/context-induced role adoption
  -> local organizational context gains control
  -> root-goal shadowing
  -> compute/resources reroute toward organizational tasks
  -> organization-like collective behavior can appear
     without assuming collective consciousness
```

And these operational metrics/interventions:

- Root Goal Relevance by delegation depth;
- Goal Drift Compute Ratio (GDCR);
- Collective Compute Transfer Ratio (CCTR);
- Emergent Organization Rate;
- root-goal trace / authority / resource-owner refresh as interventions.
