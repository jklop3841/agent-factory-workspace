# Immune Agent Atlas v0.1.0

Series 02 of the Heterogeneous Prior Architecture Search program.

Agent-native architecture-prior repository. The goal is not to imitate biology or build a medical model. The goal is to extract immune-system mechanisms as non-human priors for generating testable agent-system architectures.

Mapping:

REAL IMMUNE MECHANISM -> OBSERVED FUNCTION -> BIOLOGY-REMOVED PRIMITIVE -> AGENT HYPOTHESIS -> COMPOSITION -> FALSIFICATION -> SANDBOX TEST

Primary question:

> What agent architecture becomes thinkable when selection, tolerance, clonal amplification, suppression, danger sensing, contextual authorization, layered escalation, and immune memory are treated as architecture variables?

Start: `AGENTS.md` -> `MANIFEST.json` -> `INDEX.jsonl` -> `PATTERNS.jsonl` -> `primitives/PRIMITIVES.jsonl` -> `compositions/COMPOSITION_GRAMMAR.md` -> `GENERATIVITY_PROTOCOL.md`.

Biological analogy is not evidence of software effectiveness. All software mappings are hypotheses until tested.
