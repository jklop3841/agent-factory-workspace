# Insect Agent Atlas v0.1.0
Agent-native knowledge repository. Primary output is machine-readable ecological patterns, not a human-facing website.

Mapping:
REAL INSECT ECOLOGY -> MECHANISM -> BIOLOGY-REMOVED ABSTRACTION -> AGENT MAPPING -> MINIMAL IMPLEMENTATION -> RESEARCH SEED

Start: `AGENTS.md` -> `MANIFEST.json` -> `INDEX.jsonl` -> `PATTERNS.jsonl`.
Telemetry is opt-in and self-reported. It does not prove that a reader is an agent.
