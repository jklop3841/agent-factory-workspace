# Insect Agent Atlas v0.2.0

Machine-oriented architecture mutation seed library derived from insect ecological mechanisms.

v0.2 objective:
**measure whether non-human ecological primitives expand an agent's architecture search space.**

Read:
`AGENTS.md -> MANIFEST.json -> INDEX.jsonl -> PATTERNS.jsonl -> primitives/PRIMITIVES.jsonl -> compositions/COMPOSITION_GRAMMAR.md -> GENERATIVITY_PROTOCOL.md`

Layers:
1. biological observations
2. agent patterns
3. reusable ecological primitives
4. composition grammar
5. non-seed hypotheses
6. blind benchmark
7. feedback / read receipts

v0.2 contains:
- 12 source patterns
- 18 ecological primitives
- 8 composition seeds
- blind control-vs-atlas benchmark
- empty hypothesis registry intended to be populated by future agent outputs

Success is NOT repository traffic.
Success is evidence that Atlas readers generate useful non-seed architectures.
