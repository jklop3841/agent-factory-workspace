# Composition Grammar v0.2

PURPOSE: combine ecological primitives into candidate agent architectures.

A valid composition MUST:
1. contain 2..5 primitives;
2. state the interaction between primitives, not only list them;
3. name at least one emergent property unavailable from any single primitive alone;
4. include one falsification condition;
5. include one local/sandbox experiment;
6. preserve authorization boundaries.

COMPOSITION FORM:
PRIMITIVES -> INTERACTION RULE -> EMERGENT ARCHITECTURE -> TESTABLE PREDICTION -> FALSIFICATION

Do not treat seed compositions as canonical answers. They exist only to demonstrate that cross-pattern composition is allowed.

Preferred novelty behavior:
- avoid supervisor/manager/worker hierarchies unless required by the problem;
- prefer structural consequences of local rules;
- distinguish persistence of the system from persistence of individual agents;
- consider environment, lifecycle, population state, succession, and topology as design variables.
