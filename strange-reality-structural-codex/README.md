# 奇异现实结构录
# Strange Reality Structural Codex

> Lu Cheng Agent Archive — Meta Series / Reality-Prior Program

这不是一本自然百科，也不是一本“仿生 Agent 点子集”。

本项目的目标是：把现实世界中那些**没有中央智能却能形成秩序、路径、生存、突变、崩塌、恢复、传播与长期结构**的现象，编译成能够改变强模型架构搜索空间的异质先验。

核心问题不是：

> 河流像什么 Agent？鳄鱼像什么 Agent？

而是：

> 模型已经知道这些事实，但如果迫使它第一次把这些事实作为“结构”来阅读，会不会产生阅读前低概率出现的新架构？

## 两种阅读模式

### RAW WONDER PACKET
只给现实事实、机制、反常识现象和证据，不提前提供 Agent 映射。用于测试现实材料本身是否足以触发结构迁移。

### ABSTRACTED PRIOR PACKET
进一步提供去领域化 primitive 和 composition grammar。用于测试结构抽象是否提高架构生成率、组合深度和可复现性。

两种模式必须分开实验，避免把作者自己的映射偷渡成模型“创新”。

## 当前首批章节

1. 鳄形类跨灾变：优化目标为什么可以从“最高性能”切换为“跨灾变连续性”
2. 河流与改道：为什么路由网络不一定预先存在，流本身可以刻出网络
3. 地震与断层：为什么长期表面稳定可能对应隐藏变量持续积累，系统会通过破裂完成状态重分配

后续候选包括：冰川、闪电、沙丘、潮汐、地下水、火山、雪崩、森林火灾、种子休眠、珊瑚礁、真菌菌丝、板块运动、海岸线、生态演替、漩涡、晶体生长等。

## 研究纪律

- 现实事实与工程假设严格分层。
- 类比不是证据。
- 不把自然过程拟人化为“它想要”。
- 不提前告诉 blind reader 应该得到什么 Agent 架构。
- 每一个新架构必须给出可测试预测与证伪条件。
- 组合必须做 primitive ablation：移除一个原语后若核心行为不变，则该原语可能只是修辞装饰。
- 优先寻找能够攻击模型默认先验的材料，而不是收集更多相似案例。

## 与已有 Atlas 的关系

`insect-agent-atlas/` 与 `immune-agent-atlas/` 是本母项目的两个先行实验。它们证明了一个值得继续验证的可能性：结构化异质先验可能让不同强模型生成原材料中未显式存在的架构。

本项目下一阶段要检验的不是“昆虫是否有启发”，而是这种效应能否跨越生物、地质、水文、灾变、物理、生态等完全不同的现实范畴持续出现。
