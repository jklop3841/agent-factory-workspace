# PRD

## 1. 基本信息
- 项目名：agent-factory-workspace
- 版本：v0.1.0
- 日期：2026-03-12
- Owner：workspace bootstrap
- 状态：active

---

## 2. 一句话定义
一个以模板包为唯一基线、用于承载后续 Agent 项目文档链与真实骨架的零依赖 Agent Factory 工作区。

---

## 3. 背景
### 3.1 问题背景
当前仓库已有代码与文档混合存在，但缺少一套清晰、分层、可反复复用的 Agent Factory 工作区结构，导致基线、任务卡、handoff、运行残留容易混杂。

### 3.2 机会背景
模板包已经明确给出最小且无依赖的工作区范式，现在重建能为后续多个 Agent 项目提供统一底盘，并减少每次从零开始的沟通和搭建成本。

### 3.3 触发原因
用户要求先完整阅读模板包，并严格以其为唯一基线重建工作区，同时遵守先文档链、后项目骨架的顺序。

---

## 4. 目标
### 4.1 主目标
- 重建符合模板包文档的 Agent Factory 顶层目录树
- 保留并固定 6 个主模板文件

### 4.2 次目标
- 为首个项目生成完整文档链
- 提供一个无依赖、可验证的真实项目骨架

### 4.3 非目标
- 本轮不重构当前仓库的既有 Node 工程
- 本轮不引入自动脚手架生成器或额外依赖

---

## 5. 用户 / 使用者
### 5.1 核心用户
- 需要多轮交接的个人研究者或开发者
- 需要让 ChatGPT、Codex、Claude Code 等执行器共享同一底盘的操作者

### 5.2 使用场景
- 新建一个新的 Agent 项目
- 为执行器准备任务卡和 handoff
- 冻结 baseline、review 与 publish 制品

### 5.3 用户收益
- 结构一致，降低切换成本
- 基线、运行层、项目层分离，减少污染

---

## 6. 核心价值
### 6.1 功能价值
提供清晰目录树、模板库存和文档链，让新项目启动路径稳定可复用。

### 6.2 系统价值
作为 Agent Factory 的共享底盘，把任务组织、项目实现和运行残留分层管理。

### 6.3 商业价值
可复用于后续项目、服务交付包和对外发布的标准化工作区。

---

## 7. 需求范围
### 7.1 P0 必做
- 00 至 12 顶层目录齐全
- 6 个模板文件保留在 `06-templates/`
- 生成 PRD、SPEC、TASK CARD、HANDOFF

### 7.2 P1 应做
- 项目 README 与验证脚本
- baseline 压缩包归档到 `02-baselines/`

### 7.3 P2 可选
- 后续再补 ACCEPTANCE / REVIEW 实例

---

## 8. 功能清单
| 模块 | 功能 | 优先级 | 说明 |
|---|---|---:|---|
| workspace-root | 顶层目录树 | P0 | 按模板包 docs 重建 |
| template-layer | 模板库存 | P0 | 固定保留 6 个 master 模板 |
| doc-chain | 文档链实例化 | P0 | 先 PRD/SPEC/TASK CARD/HANDOFF |
| project-skeleton | 真实项目骨架 | P1 | 无依赖、可继续开发 |
| validation | 结构验证脚本 | P1 | 验证关键路径存在 |

---

## 9. 用户流程
### 9.1 主链路
1. 读取 baseline docs 与 templates
2. 生成项目 PRD 和 SPEC
3. 生成任务卡与 handoff
4. 在 `01-projects/` 下开始真实实现

### 9.2 异常链路
1. 若模板缺失，则从 `02-baselines/` 恢复
2. 若运行残留污染模板层，则迁移到 `10-runtime/`

---

## 10. 输入 / 输出
### 10.1 输入
- 文件：模板包 zip、3 个 docs、6 个模板
- 配置：工作区规则与项目样例配置
- 命令：PowerShell 验证命令
- 环境：Windows 文件系统

### 10.2 输出
- 制品：重建的目录树与项目骨架
- 日志：后续放入 `07-logs/`
- 报告：manifest 与 review
- 可交付包：后续可冻结到 `12-publish/`

---

## 11. 约束条件
- 平台：Windows 优先
- 运行环境：本地 PowerShell
- 依赖限制：不新增任何依赖
- 文件体积限制：模板层保持轻量
- 安全限制：不执行未知外部脚本
- 成本限制：本轮只做最小骨架

---

## 12. 风险
| 风险 | 等级 | 描述 | 应对 |
|---|---:|---|---|
| 结构污染 | 高 | 模板层混入运行残留 | 将运行输出限定到 `10-runtime/` |
| 基线漂移 | 中 | 误将现有仓库内容当作新基线 | 明确以模板包为唯一基线 |

---

## 13. 验收标准
### 13.1 可运行
- `powershell -ExecutionPolicy Bypass -File .\scripts\validate-workspace.ps1` 成功

### 13.2 可验证
- 顶层目录树存在
- 6 个模板存在
- 文档链存在

### 13.3 可交接
- 有 README
- 有配置说明
- 有运行命令
- 有残留问题说明
